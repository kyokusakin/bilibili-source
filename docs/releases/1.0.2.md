# bilibili-source 1.0.2

Fixes the Lavalink plugin packaging so `bilibili-plugin` can be used as a single self-contained plugin jar.

## Highlights

- Bundled `bilibili-common` runtime classes into `bilibili-plugin`.
- Fixed `NoClassDefFoundError: dev/lavalink/bilibili/BilibiliAudioSourceManager` when loading the plugin in Lavalink.
- Updated README examples to use the self-contained plugin jar flow.

## Artifacts

- `io.github.kyokusakin:bilibili-common:1.0.2`
- `io.github.kyokusakin:bilibili-plugin:1.0.2`

## Upgrade

1. Replace `bilibili-plugin:1.0.1` with `bilibili-plugin:1.0.2`.
2. If you were manually copying jars into `plugins/`, you now only need the `bilibili-plugin` jar.
