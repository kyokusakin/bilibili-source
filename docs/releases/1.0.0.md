# bilibili-source 1.0.0

Initial standalone release of `bilibili-source`.

## Highlights

- Split the old forked Lavalink implementation into an independent repository.
- Restructured the project into `common` and `plugin` modules similar to `youtube-source`.
- Kept legacy Bilibili configuration compatibility for existing fork users.
- Added GitHub Actions build and publish workflows.
- Added tag-based version derivation for release and snapshot artifacts.

## Artifacts

- `dev.lavalink.bilibili:bilibili-common:1.0.0`
- `dev.lavalink.bilibili:bilibili-plugin:1.0.0`

## Migration

1. Stop using the old forked server jar.
2. Use standard Lavalink.
3. Load `bilibili-plugin` through `lavalink.plugins` or the `plugins/` directory.
4. Keep legacy Bilibili config keys temporarily if needed.
