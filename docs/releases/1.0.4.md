# bilibili-source 1.0.4

Fixes Bilibili video playback when the progressive MP4 URL carries HE-AAC audio that Lavaplayer cannot decode reliably.

## Highlights

- Detect HE-AAC entries in Bilibili's DASH audio ladder.
- Use the AAC-LC DASH stream instead of the equivalent HE-AAC progressive MP4 URL.
- Select the smallest compatible AAC-LC stream and support both `baseUrl` and `base_url` response fields.
- Add playback-selection unit coverage for HE-AAC, AAC-LC, and missing DASH data.

## Artifacts

- `io.github.kyokusakin:bilibili-common:1.0.4`
- `io.github.kyokusakin:bilibili-plugin:1.0.4`

## Upgrade

1. Replace `bilibili-plugin:1.0.3` with `bilibili-plugin:1.0.4`.
2. Restart Lavalink after updating the plugin jar or dependency.
