# bilibili-source 1.0.5

Restores video metadata loading when Bilibili's view API returns HTTP 412 but the video page remains accessible.

## Highlights

- Read the video's embedded page metadata when the view API responds with HTTP 412.
- Preserve the existing API response handling for other status codes.
- Decode the fallback page as UTF-8 and report a clear error if its video metadata is unavailable.
- Add tests for the embedded state parser and missing metadata.

## Artifacts

- `io.github.kyokusakin:bilibili-common:1.0.5`
- `io.github.kyokusakin:bilibili-plugin:1.0.5`

## Upgrade

1. Replace `bilibili-plugin:1.0.4` with `bilibili-plugin:1.0.5`.
2. Restart Lavalink after updating the plugin jar or dependency.
