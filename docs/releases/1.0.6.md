# bilibili-source 1.0.6

Fixes HTTP 412 responses caused by the plugin's previous browser User-Agent when requesting Bilibili video metadata.

## Highlights

- Use a dedicated `bilibili-source/1.0` User-Agent for metadata and playback requests.
- Avoid the Apache HTTP client's default User-Agent, which can also trigger HTTP 412 on playback URL requests.
- Add a regression test for the request headers.

## Artifacts

- `io.github.kyokusakin:bilibili-common:1.0.6`
- `io.github.kyokusakin:bilibili-plugin:1.0.6`

## Upgrade

1. Replace `bilibili-plugin:1.0.5` with `bilibili-plugin:1.0.6`.
2. Restart Lavalink after updating the plugin jar or dependency.
