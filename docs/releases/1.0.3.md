# bilibili-source 1.0.3

Fixes Bilibili video playback failures caused by Lavaplayer's native AAC decoder rejecting some DASH `.m4s` audio streams.

## Highlights

- Prefer Bilibili progressive MP4 playback URLs for video tracks.
- Keep DASH AAC audio as a fallback when no progressive URL is available.
- Avoid decoder failures such as `Error from decoder 16394` on affected videos.
- Harden the GitHub Actions publishing workflow for Central Portal environment secrets.

## Artifacts

- `io.github.kyokusakin:bilibili-common:1.0.3`
- `io.github.kyokusakin:bilibili-plugin:1.0.3`

## Upgrade

1. Replace `bilibili-plugin:1.0.2` with `bilibili-plugin:1.0.3`.
2. Restart Lavalink after updating the plugin jar or dependency.
